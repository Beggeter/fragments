🔗 Настройка Telegram Stars Webhook

Инструкция:
  1. Создайте Stars бота через @BotFather
  2. Получите токен бота
  3. Введите токен и URL webhook'а ниже
  4. Нажмите "Настроить Webhook"
Примеры URL для разработки:
• ngrok: https://abc123.ngrok.io/api/stars/webhook
• localhost: http://localhost:3001/api/stars/webhook
• production: https://yourdomain.com/api/stars/webhook
Проверка webhook'а:
После настройки отправьте тестовый запрос:
curl -X POST "https://api.telegram.org/bot/YOUR_BOT_TOKEN/getWebhookInfo"
