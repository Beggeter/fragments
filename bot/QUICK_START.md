# 🚀 Быстрый запуск Telegram бота

## 1. Создание бота (5 минут)

1. **Найдите @BotFather в Telegram**
2. **Отправьте `/newbot`**
3. **Введите имя бота**: "Fragments Game"
4. **Введите username**: "fragments_game_bot"
5. **Сохраните токен**

## 2. Настройка Web App (2 минуты)

1. **Отправьте `/setmenubutton` боту @BotFather**
2. **Выберите вашего бота**
3. **Введите URL**: `https://your-domain.com`
4. **Введите текст**: "🎮 Играть"

## 3. Запуск бота (3 минуты)

```bash
# Перейдите в папку бота
cd bot

# Запустите автоматическую настройку
npm run setup

# Установите зависимости
npm install

# Запустите бота
npm run dev
```

## 4. Тестирование (1 минута)

1. **Найдите бота в Telegram**
2. **Отправьте `/start`**
3. **Нажмите "🎮 Играть"**
4. **Наслаждайтесь игрой!**

## 🎯 Результат

После выполнения всех шагов у вас будет работающий Telegram бот с кнопкой "🎮 Играть", которая открывает ваше веб-приложение прямо в Telegram!
