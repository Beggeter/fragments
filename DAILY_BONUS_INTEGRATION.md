# Интеграция ежедневных бонусов с фронтендом

## Обзор

Система ежедневных бонусов полностью интегрирована с фронтендом. API предоставляет данные о бонусах, а фронтенд отображает их в удобном интерфейсе.

## Компоненты

### 1. Хук `useDailyBonus`

**Файл:** `hooks/useDailyBonus.ts`

Основной хук для работы с ежедневными бонусами:

```typescript
const {
  bonusData,           // Данные о бонусах из API
  isLoading,           // Состояние загрузки
  error,               // Ошибки
  claimBonus,          // Функция получения бонуса
  hasZenSubscription,  // Есть ли ZEN подписка
  currentWeek,         // Текущая неделя
  currentDay,          // Текущий день
  canClaimToday,       // Можно ли получить бонус сегодня
} = useDailyBonus();
```

### 2. Компонент `DailyBonusModal`

**Файл:** `components/DailyBonusModal.tsx`

Модальное окно для отображения ежедневных бонусов.

#### Пропсы:
- `isOpen: boolean` - Открыто ли модальное окно
- `onClose: () => void` - Функция закрытия
- `onOpenShop?: () => void` - Функция открытия магазина (для ZEN подписки)

#### Функциональность:
- Отображает текущую неделю и день
- Показывает бонусы для обычных пользователей и ZEN подписчиков
- Обрабатывает клики на карточки бонусов
- Автоматически обновляет состояние после получения бонуса

## Логика работы

### 1. Отображение бонусов

- **Обычные пользователи:** Видят классические бонусы + затемненную секцию ZEN
- **ZEN подписчики:** Видят только ZEN бонусы

### 2. Получение бонусов

#### Клик на карточку:
- **Обычная карточка:** Сразу получает бонус
- **ZEN карточка:** 
  - Если есть подписка → получает бонус
  - Если нет подписки → открывает магазин

#### Кнопка "Забрать":
- Получает бонус для текущего дня
- Для ZEN подписчиков начисляются оба варианта бонуса

### 3. Статусы бонусов

- `available` - Доступен для получения
- `claimed` - Уже получен
- `locked` - Заблокирован (будущие дни)

### 4. Автоматическое обновление

- При получении бонуса состояние обновляется автоматически
- Если получены все 7 бонусов недели, открывается следующая неделя
- Прогресс сбрасывается при пропуске дня

## Типы данных

### DailyReward
```typescript
type DailyReward = 
  | {
      type: "currency";
      amount: number;
      status?: RewardStatus;
    }
  | {
      type: "booster";
      amount: number;
      boosterType: string;
      status?: RewardStatus;
    };
```

### RewardStatus
```typescript
type RewardStatus = "claimed" | "skipped" | "available" | "locked";
```

## Иконки

Система автоматически отображает правильные иконки:
- **Валюта:** `/crystal.svg`
- **Бустеры:**
