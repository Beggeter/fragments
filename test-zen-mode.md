## Как протестировать

### 1. Подготовка
1. Убедитесь, что у вас есть роль tester/admin/premium
2. Запустите миграцию базы данных:
   ```bash
   npm run db:migrate
   ```

### 2. Тестирование в браузере
1. Откройте приложение в браузере
2. Войдите как admin (если в dev режиме)
3. В главном меню должна появиться активная кнопка "Zen"
4. Нажмите на кнопку "Zen"
5. Проверьте:
   - Загружается ли Zen режим
   - Генерируются ли простые фигуры
   - Работает ли сохранение
   - Правильный ли дизайн

### 3. Тестирование API
1. Проверьте создание Zen игры:
   ```bash
   curl -X POST http://localhost:3000/api/users/610936383/zen-game-sync \
     -H "Content-Type: application/json" \
     -H "Authorization: Bearer YOUR_TOKEN" \
     -d '{
       "boardState": {"grid": [], "width": 8, "height": 8},
       "currentPieces": [],
       "score": 0,
       "level": 1,
       "gameMode": "zen"
     }'
   ```

2. Проверьте получение Zen игры:
   ```bash
   curl -X GET http://localhost:3000/api/users/610936383/zen-game \
     -H "Authorization: Bearer YOUR_TOKEN"
   ```

### 4. Проверка базы данных
1. Проверьте, что в таблице `user_games` появились записи с `game_mode = 'zen'`
2. Убедитесь, что поля `is_active`, `final_score`, `game_data` работают корректно

## Возможные проблемы

### 1. Ошибки миграции
- Если миграция не проходит, проверьте, что база данных доступна
- Возможно, нужно пересоздать миграцию

### 2. Ошибки API
- Проверьте, что все импорты корректны
- Убедитесь, что сервисы обновлены для поддержки gameMode

### 3. Проблемы с интерфейсом
- Проверьте, что все компоненты правильно импортированы
- Убедитесь, что типы TypeScript корректны
